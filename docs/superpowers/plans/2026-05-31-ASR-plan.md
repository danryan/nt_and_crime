## Worklist

1. Shim data (the bulk): full `scale_names_short` (OC_scales.cpp); `kIntSeqLen`
   (OC_strings.h); `mult`/`integer_sequence_names`/`integer_sequence_dirs` and the
   8 digit tables (globals.cpp), token-diffed against vendor; `SlewedValue` +
   `Atten` (util_math.h); `bitmap_hold_indicator_4x8` (OC_bitmaps.h + menus.cpp);
   `randomSeed` (Arduino.h, NT_OC_APP_TU-guarded).
2. Manifest `ASR.h` (GUID `OCAS`).
3. App `ASR.cpp` (PASSENCORE template; exclude mask index 3;
   `dispatch_custom_ui_factory<true>`; `ui_events.h` + `util/util_math.h` before
   APP_ASR.h; `MENU_REDRAW`; `ENABLE_APP_ASR`; test seams).
4. Makefile: `OC_APP_LIST += ASR`; `peaks_bytebeat` dep; add `popcountdi2.c` to
   `COMPILER_RT_OBJS`.
5. Test `test_oc_app_ASR.cpp`. Build, enumerate first-compile gaps with
   `g++ -ferror-limit=0`, get green (probe `enabled_setting_at` for the
   direction-2 cursor position).
6. ARM: `make build/arm/ASR.o`; confirm `.text` under cap and `nm` clean (the
   ARM build does not force-include util_math.h, and __popcountdi2 must resolve).
7. Regression: full OC-app suite green; a hem applet and an existing OC app still
   build on ARM (the popcountdi2 / globals.cpp changes are shared).
8. Docs: ASR lessons paragraph in CLAUDE.md; `markdownlint` the docs + CLAUDE.md.
9. Commit on `dr/oc-apps-port-2`.

## Abort budget

- Step 5/6: more than 2 unforeseen poison shadows -> halt.
- Step 6: `.text` over ~82 KB -> halt.
- Step 7: any other OC app or hem applet regresses -> halt and fix.

## Outcome

Shipped. Host 7/7 (80 assertions). ARM `.text` 33074 B. Full OC-app suite (12
binaries) and ARM regression (Cumulus, Harrington1200, DQ) clean. The
