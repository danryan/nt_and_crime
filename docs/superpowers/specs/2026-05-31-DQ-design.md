## Recipe (multi-channel facade, per-channel mid-array subset)

DQ follows the BBGEN quad-facade template with N = 2, plus a within-channel remap
that skips the four U16 masks. The PASSENCORE precedents (the `OC::UI` alias for a
vendor scale editor, the full `scale_names` table, `OC_scale_edit.h` symbols) are
reused.

### plugins/apps/DQ.cpp

1. `#define NT_OC_APP_TU 1`. `#include "UI/ui_events.h"` FIRST (before the
   runtime) so the shim `OC_apps.h` aliases `OC::UI` to `::UI` for the vendor
   `OC::ScaleEditor<DQ_QuantizerChannel>` member of `dq_state` (PASSENCORE
   precedent).
2. Include the runtime, dispatch, the OC shim headers DQ references including
   `OC_visualfx.h` and `util/util_turing.h` (the channel uses
   `util::TuringShiftRegister` without self-including it), the manifest,
   `distingnt/api.h`, `<cstring>`, `<new>`.
3. `namespace menu = OC::menu;`. Define `uint_fast8_t MENU_REDRAW = 1;` (vendor
   extern, like Harrington1200).
4. `#define ENABLE_APP_METAQ 1` (NOT `ENABLE_APP_DQ` -- the vendor guard is
   METAQ, the ENVGEN non-mechanical-guard lesson), then `#include "APP_DQ.h"`.
5. `struct DQInstance : public oc_runtime::AppAlgorithm {};`. Build
   `OC::App the_dq_app` from the `DQ_*` thunks (reinterpret_cast the two
   `UI::Event` handlers, as the template).
6. Subset constants: `kNumChannels = NUMCHANNELS (2)`, `kMaskFirst =
   DQ_CHANNEL_SETTING_MASK1 (9)`, `kNumMasks = 4`, `kExposedPerChannel =
   DQ_CHANNEL_SETTING_LAST - 4 (27)`, `kNumSettings = 54`. `phys_in_channel(w) =
   w < kMaskFirst ? w : w + kNumMasks` (captureless, compile-time constants).
7. `make_dual_facade`: `instance = dq_quantizer_channels` (array base);
   `get_value`/`apply_value`/`value_attr_at` apply `c = idx / kExposedPerChannel`,
   `phys = phys_in_channel(idx % kExposedPerChannel)`; `save`/`restore`/
   `storage_size` overridden to `DQ_save`/`DQ_restore`/`DQ_storageSize` (full
   per-channel blob including masks); `param_name` returns the channel-prefixed
   name (`"1 " / "2 "` + value_attr name) from a file-scope `char[54][16]` built
   once at construct.
8. `calculateRequirements`: `numParameters = kIoParamCount + kNumSettings (66)`.
9. `_NT_factory` (api.h field order); `.customUi =
   dispatch_custom_ui_factory<true>` (DQ reads `EVENT_BUTTON_LONG_PRESS`).
10. Test seams (non-static): `dq_get_setting`/`dq_apply_setting`
    (channel, physical-setting), `dq_num_channels`, `dq_settings_per_channel_total`
    (31), `dq_exposed_per_channel` (27), `dq_setting_count` (54),
    `dq_settings_param_base`, `dq_phys_in_channel`, `dq_get_mask`/`dq_set_mask`
    (channel, slot), `dq_get_outputs`, `dq_arm_sentinel`.

### shim/include/oc_app_manifests/DQ.h

`guid = NT_MULTICHAR('O','C','D','Q')`, name "Dual Quantizer". 4 CV in, 4 CV out
(Ch1 pitch, Ch2 pitch, Ch1 aux, Ch2 aux = DAC A,B,C,D), 4 trig in.

### Shim additions

- `OC::Strings::{cv_input_names, channel_trigger_sources, TM_aux_cv_destinations}`
  (declare in OC_strings.h, define in globals.cpp, bytes verbatim from vendor).
- `OCTAVES` macro in shim OC_config.h.
- `OC::DAC::pitch_to_scaled_voltage_dac` (collapse to pitch_to_dac) and
  `get_octave_offset` (= pitch_to_dac at zero pitch) in OC_DAC.h.
- `menu::SettingsListItem::Draw_PW_Value` in OC_menus.h.

### Makefile

`OC_APP_LIST += DQ`; `VENDOR_DEPS_DQ :=` and `VENDOR_DEP_HOST_SRCS_DQ :=` empty.

## Test plan (harness/tests/test_oc_app_DQ.cpp)

- Factory/registration: GUID `OCDQ`; 2 channels; 31 total / 27 exposed per
  channel; 54 flat.
- Subset remap: `dq_phys_in_channel(8) == SCALE_SEQ`, `(9) == SEQ_MODE` (masks
  skipped); no exposed row maps onto a mask slot.
- Draw renders.
- Output smoke: route CV inputs, step, assert the four DAC outputs are not all
  zero (the ISR -> quantizer -> DAC path runs). Exact main pitch not asserted
  (shim DAC-model limitation; hardware-smoke concern).
- Settings + mask round-trip: mutate exposed settings on both channels plus a
  mask per channel, serialise/deserialise, assert all survive (masks prove the
  full-blob hooks).
- Param sync: a flat row in channel 1's block updates channel 1's physical
  setting; channel 0 untouched. Offset push-back with `set_parameter_offset(1)`.

## Footer

### Recipe spot-check

BBGEN quad-facade verified to dispatch logical idx via `idx / per` and
`idx % per`; the within-channel `phys_in_channel` skip composes cleanly because
the masks are a contiguous block. `construct_with_facade` reads all three
accessors by logical index, so the remap is coherent.

### Per-entry verification (3 settings traced against vendor)

- Within-row 8 -> phys 8 = `DQ_CHANNEL_SETTING_SCALE_SEQ`: vendor attr
  `{0, 0, NUM_SCALE_SLOTS-1, "scale #", dq_seq_scales, U8}` (APP_DQ.h:1125).
  int16-safe. Exposed. OK.
- Within-row 9 -> phys 13 = `DQ_CHANNEL_SETTING_SEQ_MODE`: vendor attr
  `{0,0,3,"seq_mode",dq_seq_modes,U4}` (APP_DQ.h:1130). int16-safe. The four masks
  at phys 9..12 are skipped. OK.
- Phys 9..12 = `DQ_CHANNEL_SETTING_MASK1..4`: vendor attr
  `{65535,1,65535,"--> edit",NULL,U16}` (APP_DQ.h:1126-1129). Max 65535 > int16.
  Correctly excluded. OK.

3 of 3 consistent with vendor source.

### Shim prereq verification

- OC aggregation supplies braids_quantizer + OC_scales; DQ needs no per-app
  vendor `.cpp`.
- `OC_visualfx.h` / `util/util_history.h` / `util/util_turing.h` header-only;
  `extern/dspinst.h` has a portable C `#else` fallback. No new poison shadows.
- New shim symbols enumerated above; `g++ -ferror-limit=0 -fsyntax-only`
  confirmed the complete set (the `SettingsBase<...,31>` red-herring errors
  cleared once `util::TuringShiftRegister` was in scope, the ENVGEN lesson).
- GUID `OCDQ` unused.
